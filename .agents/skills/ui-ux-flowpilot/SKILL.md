# FlowPilot UI/UX direction

## Brand feel

Premium B2B SaaS: calm, technical, clear and trustworthy. Avoid stereotypical AI visuals, excessive glassmorphism, random purple gradients and decorative complexity that makes the product harder to read.

## Core palette

Use a near-black/deep-navy base, white/off-white type, muted slate secondary text and one restrained electric-blue accent. Keep contrast high enough for small mobile video previews.

## Typography

Use a modern sans-serif system stack unless the project already ships a font. Strong hierarchy matters more than novelty. Headlines are compact and heavy; body/UI copy is readable and neutral.

## Product UI

- simple cards and panels,
- obvious states: incoming → AI draft → approved → sent,
- visible approval action,
- realistic but non-sensitive example messages,
- no fake dashboards full of meaningless numbers,
- generous spacing and 16–24px corner radii on desktop; exaggerate sizing for video mockups.

## Motion UI

Motion should explain state changes. Use position, opacity, scale and progress before decorative particles/glows. In reels, product state should be understandable with audio off.

## Accessibility/quality

Maintain strong contrast, visible focus states for real web UI, predictable controls and responsive layouts. Avoid using color as the only indicator of state.
