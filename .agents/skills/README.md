# FlowPilot / Kapitalownia Agent Skills

Project-level Agent Skills for the FlowPilot/Kapitalownia stack.

## Installed skills

- `flowpilot-orchestrator` — routes work to the correct specialist workflow.
- `engineering-workflow` — spec-first implementation, verification, security, review.
- `make-automation` — Make scenarios, webhooks, routing, approvals, retries.
- `supabase-crm` — Postgres/Supabase CRM, RLS, auth, realtime, migration from JSON.
- `document-intelligence` — grant regulations, PDFs, DOCX/XLSX, structured evidence, Docling.
- `remotion-content-engine` — automated TikTok/Reels/Shorts generation with Remotion.
- `browser-qa` — Playwright-style browser and E2E validation.
- `agents-sdk-orchestration` — specialized AI agents, handoffs, guardrails, tracing, human approval.
- `funding-web-monitoring` — Firecrawl-style monitoring of official program sources.
- `omnichannel-inbox` — Chatwoot/shared-inbox patterns for Messenger/Instagram/WhatsApp/email.
